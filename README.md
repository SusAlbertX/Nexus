# Nexus
Infraestructura de red y sistemas para un club de eSports

## Equipo
- **Sergio**: Coordinación, redes y sistemas.
- **Albert**: Documentación, desarrollo web y pruebas.

## ¿De que va el repositorio?
Aquí vamos a guardar toda la documentación en latex, el codigo de la web y las configuraciones de los servidores del club Nexus.

## Roles y tareas
- **Coordinación y Redes (Sergio):** Encargado de montar la red, configurar los servidores (DHCP, DNS, etc.) y organizar el Kanban.
- **Documentación y Web (Albert):** Encargado de escribir la memoria en LaTeX, hacer la página web con HTML/CSS y probar que todo funcione.

## ¿Cuándo está terminada una tarea?
Para que una tarea pase a la columna de "Hecho" tiene que cumplir:
1. Que funcione y hayamos hecho pruebas.
2. Que esté apuntada en el documento de latex o en el README.
3. Que el Issue este cerrado en GitHub y el Kanban actualizado.
